## Project status

This project is no longer actively maintained.

Cryptography support is now provided through the lwIP-CE TLS API which ports primitives from this library and some new ones into an even more powerful library. lwIP-CE also has full test coverage--unit tests, CAVP-style vector testing, timing analysis, etc. Please use that API for new development.


# CryptX

CryptX provides cryptography for the TI-84+ CE graphing calculator.

## Getting Started with CryptX

Visit the [CryptX Documentation](https://acagliano.github.io/cryptx) for help with using 
the library, documentation, cryptanalysis, credits, and more.
